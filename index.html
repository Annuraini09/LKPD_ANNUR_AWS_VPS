Pengenalan Konsep VPS & Cloud

Shared Hosting

Layanan hosting di mana satu server fisik dibagi bersama banyak pengguna/website. Sumber daya (RAM, CPU) dipakai bersama-sama, sehingga harganya murah tetapi performa bisa saling mempengaruhi.

Dedicated Server

Penyewaan satu server fisik secara utuh untuk satu pengguna saja. Sumber daya maksimal dan performa tinggi, tetapi harganya relatif mahal dan pengelolaannya lebih rumit.

Amazon Lightsail

Layanan Virtual Private Server (VPS) pemula dari AWS yang sudah disederhanakan (bundling instance, penyimpanan, dan transfer data dengan harga tetap per bulan). Cocok untuk developer atau pemula.

Amazon EC2 (Elastic Compute Cloud)

Layanan komputasi awan (cloud computing) dari AWS yang skalabel dan fleksibel. Memberikan kontrol penuh atas mesin virtual (instance) dengan berbagai pilihan spesifikasi dan konfigurasi tingkat lanjut.
